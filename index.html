Support

Help Center

Guidance for using Rhymo's website and account features.

How do I sign in?

Choose Login with Discord and approve the identity permission. The backend validates the callback and creates a session.

Why can't I log in?

Confirm that the backend is deployed, the redirect URL exactly matches the Discord Developer Portal setting, and the frontend points to the correct backend origin.

How do I add Rhymo?

Open Settings and select Add to Discord. Review the requested permissions on Discord before approving installation.

Where can I find commands?

Use Global Search to find available command information. A live command catalog requires a configured data source.
